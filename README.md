# Permian Software & Automation

**Practical software automation for oilfield, industrial, and field-service companies in the Permian Basin.**

Based in **Odessa, Texas**, Permian Software & Automation helps small and midsize field-service businesses reduce repetitive office work without forcing them into a giant software project.

## What we automate

- Service requests and work-order intake
- Technician and field reports
- RFQ and quote intake
- Customer status updates and routine follow-up
- Document and spreadsheet processing
- Repetitive internal administrative workflows

## Workflow Automation Pilot — $1,250

We start with one repetitive business process. We map how it works today, automate the practical parts, test it with real work, document it, and hand it over.

**No long-term contract is required for the pilot.**
